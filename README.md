# CityMETER: Hotel

**ห้องพักกระจุกอยู่ตรงไหน และใกล้รถไฟฟ้าแค่ไหน** — เดโมแผนที่ 3 มิติของที่พักทั่วประเทศไทย ที่อ่านห้องพักที่แหล่งบันทึกเป็นยอดต่อเขต/อำเภอ พร้อมระยะถึงสถานีรถไฟฟ้าและศูนย์การค้า เครือโรงแรม ที่พักใกล้เคียงขนาดใกล้กัน ราคาที่บันทึก และที่มาของทุกตัวเลข

- เว็บ: https://montri-th.github.io/hotel/
- ระบบจริงของ CityMETER: https://landometer.com/v3/citymeter?d=hotel
- รุ่น 0.2.0 · 1 พฤศจิกายน 2569 · ชีตวิจัยตรวจแหล่ง 1 พฤศจิกายน 2569 (ตรวจจำนวนห้องซ้ำ 178 แห่ง) · ขอบเขต production อ่าน 1 พฤศจิกายน 2569

ข้อค้นพบแรก (snapshot ปัจจุบัน ไม่กรอง): **35% ของห้องพักในกรุงเทพมหานครที่ระบุเขตได้ (53,516 จาก 152,864 ห้อง) อยู่ใน 3 เขต — คลองเตย วัฒนา ราชเทวี** · ห้องพักใน 3 เขตนี้ 67% อยู่ห่างสถานีรถไฟฟ้าที่เปิดแล้วไม่เกิน 500 ม. (25,768/38,690 ห้องที่มีพิกัด) เทียบ 42% (32,732/77,957) ในเขตอื่นของกรุงเทพฯ · อำเภอที่มีห้องพักมากที่สุดของประเทศคือบางละมุง ชลบุรี 62,561 ห้อง

> ชุดข้อมูล CityMETER Hotel · แหล่ง CityMETER Hotel V3 ทะเบียนที่พัก ททท. และหน้าทางการ · ตรวจ 1 พ.ย. 2569 · ขอบเขต เขต/อำเภอของ CityMETER ทั่วประเทศ — ห้อง = จำนวนห้องที่แหล่งบันทึก ไม่ใช่ห้องว่างต่อคืน · 79 แห่งไม่ทราบจำนวนห้อง ไม่นับเป็น 0

## ใช้งาน

```sh
npm start   # http://127.0.0.1:4173/
npm test    # unit tests บนข้อมูลจริง (node --test)
```

เป็น static site ไม่มี build step และไม่ต้อง `npm install` (Node ≥ 20 สำหรับ tests, Python 3 สำหรับ server) แผนที่โหลด MapLibre GL 5.6.2 จาก unpkg และ tiles/glyphs จาก OpenFreeMap; basemap สร้างเองใน `js/map-style.js` กราฟไม่ใช้ไลบรารีภายนอก ถ้าแผนที่โหลดไม่ได้ ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้

## สิ่งที่สำรวจได้

- **ข้อค้นพบแรกแบบ 3 มิติ:** โฟกัสเขต/อำเภอที่มีห้องพักมากที่สุด (ไม่เกิน 3) ของจังหวัดที่มีห้องพักระดับเขตมากที่สุด บอกสัดส่วน ตัวตั้ง ตัวหาร สัดส่วนใกล้รถไฟฟ้าเทียบส่วนอื่นของจังหวัด และพื้นที่ที่มากที่สุดนอกจังหวัด — ไม่ตัดผ่านค่าที่เท่ากัน และไม่โฟกัสทุกเขตของจังหวัด
- **ห้องพัก | ที่พัก:** สลับมาตรวัดในคำอธิบายแผนที่ แผนที่ ป้าย ข้อค้นพบ อันดับ และกราฟเปลี่ยนพร้อมกัน (สเกล `li.supply` สำหรับห้อง และ `count` สำหรับแห่ง ครบ 41 ระดับของ LDS)
- **สถานีรถไฟฟ้า (CityMETER Transit):** วงกลมเล็กบนแผนที่ กดเพื่อดูที่พักในรัศมีระยะตรง 500 ม. พร้อมวงรัศมีบนแผนที่ และลิงก์ไปสถานีเดียวกันใน CityMETER Transit
- **ขนาดสัญลักษณ์ตามจำนวนห้อง:** พื้นที่ของสัญลักษณ์เพิ่มตามห้องที่บันทึก สีและรูปทรงยังบอกประเภท วงโปร่ง = ไม่ทราบจำนวนห้อง
- **ชื่อที่พักกลางจอ:** ตั้งแต่ระดับไซต์ ชื่อสั้นของที่พักที่ห้องมากและราคาที่บันทึกสูงก่อน ไม่เกิน 9 ป้าย (มือถือ 5) ป้ายเป็นตัวอักษรอ่านง่าย: แบรนด์ตัวหนา + ชื่อสาขา ชี้แล้วเห็นการ์ดพร้อมโลโก้เครือขนาดอ่านได้ (107 แบรนด์) และไอคอน: ประเภท ห้อง ราคาที่บันทึก ภูมิประเทศ
- **ภูมิประเทศ:** ในพื้นที่ที่มีเนินเขา เมื่อซูมถึงระดับไซต์ แผนที่แสดงพื้นดิน 3D (ขยาย 1.5 เท่า) และเงาเนินเขาเอง รวมถึงตอนเปิดดูอาคารหรือที่พัก — อาคารตั้งอยู่บนเนินตามจริง แผงที่พักบอกความสูงพื้นดิน ต่างระดับ ทะเลใกล้แค่ไหน และต้นไม้ตามแผนที่ OSM
- **อาคารรายพื้นที่:** แต่ละ อปท. (กรุงเทพฯ รายเขต) ใช้อาคาร CityMETER Building V4 เมื่อมีอาคารมากกว่า OpenStreetMap ตั้งแต่ 15% ขึ้นไป ไม่เช่นนั้นใช้ OSM; อาคารที่ OSM ทำเป็นหลายส่วน (หลายระดับ) ยังใช้ OSM เพื่อไม่ให้รายละเอียดหาย ความสูงของ CityMETER เป็นค่าประมาณ
- **โรงแรมหนึ่งแห่ง:** มุมมองอาคาร 2-point perspective · ห้อง ขนาด เครือ ราคาที่บันทึก (ไม่ทราบช่วงเวลา) ห้องประชุมตามทะเบียน ททท. สถานีและศูนย์การค้าที่ใกล้ที่สุด อาคารเดียวกันตามงานวิจัย · **ที่พักใกล้เคียงขนาดใกล้กัน** (ประเภทเดียวกัน ½–2 เท่า ระยะตรง 2 กม.)
- **เครือ:** กรองตามเครือเพื่อดูแบรนด์ ห้อง แห่ง จังหวัด และสัดส่วนใกล้รถไฟฟ้า
- **ถามต่อใน Google:** ทุกมุมมองมีปุ่มถาม Google AI (AI Mode) ด้วยคำถามที่ตรงกับสิ่งที่กำลังดู พร้อม Google Maps และ Street View เมื่อมีพิกัด ผลลัพธ์เป็นของ Google ไม่ใช่ข้อมูล CityMETER
- **เส้นทาง:** ประเทศไทย › จังหวัด › เขต/อำเภอ ใช้รหัสเดียวกับ CityMETER production และเปิดพื้นที่เดียวกันในระบบจริงได้ (`?d=hotel`)
- **ลิงก์ตรง:** `?metric=count` · `?area=1039` · `?areas=1033,1037,1039` · `?areas=all` · `?province=PKT` · `?group=resort` · `?size=s4` · `?chain=HGRP-accor` · `?hotel=<id>` · `?station=<id>` · `?view=mix` · `?view3d=0`

## ข้อมูล

- `data/hotels.json` — 30,729 รายการที่พักจากชีตวิจัย (ไม่เผยแพร่ชีตหรือไฟล์ export) — `scripts/build-data.py`
- `data/area-index.json`, `data/frames/{CODE}.json`, `data/provinces.geojson` — เขต/อำเภอและจังหวัดของ CityMETER production — `scripts/build-boundaries.py`
- `data/boundary-receipts.json` — ใบรับของทุก response จาก production base info
- `data/building-units/index.json`, `data/building-units/{CODE}.json` — แหล่งอาคารราย อปท./เขต ตามเกณฑ์ 15% พร้อมจำนวนที่ใช้ตัดสิน — `scripts/build-building-units.py`
- วิธีทั้งหมด ข้อจำกัด และงานวิจัยที่ต้องตามต่อ: `DATA_METHOD.md` · กลยุทธ์ผลิตภัณฑ์: `PRODUCT_STATEMENT.md` · สำหรับนักพัฒนา: `handoff/START_HERE.md` · สำหรับ agent: `llms.txt`
