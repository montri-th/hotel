# กราฟเปรียบเทียบพื้นที่

ถาดกราฟด้านล่างแผนที่ (“เปรียบเทียบพื้นที่”) มีสามมุมมอง ใช้ข้อมูลชุดเดียวกับข้อค้นพบแรกและ choropleth คือ **scopeRows** (แถวตามตัวกรองค้นหา/ประเภท/ขนาด/จังหวัด/เครือ ก่อนเลือกพื้นที่) และมาตรวัดเดียวกับแผนที่ (ห้องพัก หรือ ที่พัก) แท่งและช่องเป็นปุ่ม: ของเขต/อำเภอเปิดพื้นที่นั้น ของเครือตั้งตัวกรองเครือและเปิดบัตรเครือ กราฟวาดด้วย HTML ของเดโมเอง ไม่ใช้ไลบรารีกราฟ (`js/charts.js`, `js/chart-model.js`)

| มุมมอง (`?view=`) | คำถาม | การเข้ารหัส | ตัวชี้วัด | ขอบเขต |
|---|---|---|---|---|
| เขต/อำเภอ (`areas`, ค่าเริ่มต้น) | เขต/อำเภอไหนมีห้องพัก (หรือที่พัก) มากที่สุด | แท่งแนวนอนเรียงลำดับ สีระดับเดียวกับแผนที่ (`li.supply` หรือ `count`) ตัวเลขอยู่นอกแท่ง ใต้ชื่อบอกจังหวัดและอีกมาตรวัดหนึ่ง คำบรรยายบอกยอดที่ระบุได้แค่จังหวัด | ห้อง หรือ แห่ง | 20 เขต/อำเภอแรก |
| ประเภทที่พัก (`mix`) | เขตที่มีมากเป็นที่พักประเภทใด | matrix เขต × 7 ประเภท ทุกช่องขนาดเท่ากัน สีช่อง = 41 ระดับตามลำดับค่าของช่องในตาราง หัวคอลัมน์มีรูปทรงของประเภท | ห้อง หรือ แห่ง ต่อช่อง | 12 เขต/อำเภอแรก |
| เครือ (`chains`) | เครือใดมีห้องพัก (หรือที่พัก) มากที่สุดในตัวกรองนี้ | แท่งแนวนอนสีพื้นฐานกลางเดียว (เครือไม่ใช่หมวดของแผนที่) ใต้ชื่อบอกอีกมาตรวัดหนึ่งและจำนวนแบรนด์ | ห้อง หรือ แห่ง | 20 เครือแรกจากที่พบ (เฉพาะที่พักที่ชุดข้อมูลระบุเครือ) |

## ความหมายของการเข้ารหัส

- **ความยาวแท่ง** เทียบกับค่าสูงสุดในกราฟ ตัวเลขจริงอยู่ข้างแท่งเสมอ ค่าเท่ากันเรียงตามอีกมาตรวัดหนึ่งแล้วตามชื่อ
- **Matrix ช่องเท่ากันทุกช่อง** ขนาดช่องไม่มีความหมาย ช่อง 0 คือ measured zero (ระดับ 0 + เส้นขอบศูนย์) ไม่ใช่ช่องว่าง
- **ห้องที่ไม่ทราบ** ไม่ถูกนับเป็น 0 ห้องในแท่งหรือช่องใด

## สีและระดับ

- ห้องพักต่อพื้นที่: `li.supply` (Location Intelligence Profile, scaleVersion `671112f3…c497`) · ที่พักต่อพื้นที่: `count` (`4ff5c1fb…0980`) — ยอดรวม ไม่ใช่ความหนาแน่น · ครบ 41 ระดับตามลำดับค่า (`js/scales.js#buildRamp`) สีเดียวกันทั้งสองธีม
- ประเภทที่พัก: categorical `landometer-series-10-v8` ผูกด้วย id พร้อมรูปทรงประจำ series ไม่ใช้ดาว
