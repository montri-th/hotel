# CityMETER Hotel — first useful value

Build Card ของสัญญาการใช้งานครั้งแรกของเดโมนี้ ใช้ LDS 0.9.7 release `v0.9.7-owner.1` เอกสาร standalone `lds-0.9.7-landometer-standalone-r1` SHA-256 `d3085cbc0a50195f1cbf0c77b1d77c0d19b84364daf2948eb367348d65432d96` และ Location Intelligence Profile `location-intelligence-profile-lds-0.9.7-r1` SHA-256 `5d4856041709735d3a04d4a510a88b551df86c211fdcab8a0707e8fe7c9efc3b` (สเกล `li.supply`) ไม่ใช่ใบรับรองความสอดคล้องทั้งระบบหรือผลผ่านทุกเบราว์เซอร์

## First Aha — AHA-01

**ความเข้าใจแรกที่มีประโยชน์:** ห้องพักที่แหล่งบันทึกกระจุกอยู่เขต/อำเภอใด มากแค่ไหนเมื่อเทียบกับทั้งจังหวัด ใกล้สถานีรถไฟฟ้าที่เปิดแล้วแค่ไหนเมื่อเทียบกับเขตอื่น และนอกจังหวัดนั้นมีมากที่สุดที่ไหน ผู้ใช้เริ่มสำรวจระดับพื้นที่ได้ทันทีโดยไม่ต้องเรียนรู้ตัวกรองก่อน

ข้อความเริ่มต้น (snapshot ชีตตรวจ 1 พ.ย. 2569): **“35% ของห้องพักในกรุงเทพมหานครที่ระบุเขตได้ อยู่ใน 3 เขตนี้”** คลองเตย · วัฒนา · ราชเทวี — 53,516 จาก 152,864 ห้อง · “ห่างสถานีรถไฟฟ้าที่เปิดแล้วไม่เกิน 500 ม.: 67% ของห้องพักใน 3 เขตนี้ (25,768/38,690) · เขตอื่นของกรุงเทพมหานคร 42% (32,732/77,957)” · ข้อค้นพบรอง “นอกกรุงเทพมหานครมากที่สุด: อำเภอบางละมุง ชลบุรี 62,561 ห้อง — มากกว่าเขตใดในกรุงเทพมหานคร” ตัวเลขทั้งหมดคำนวณจากข้อมูลทุกครั้ง ไม่ใช่ค่าคงที่ใน markup

แผนที่เปิดเป็นเมือง 3 มิติ (preset `city`) ที่โฟกัส 3 เขตนั้นอัตโนมัติ (focus mode `auto`, URL ไม่มี `areas`): สี choropleth `li.supply` สัญลักษณ์ที่พักตามประเภท (ขนาดตามจำนวนห้อง เฉพาะแถวที่มีจุด) สถานีรถไฟฟ้าเป็นวงกลมเงียบ และมวลอาคารมุมโค้งเฉพาะในโฟกัส ส่วนอื่นของเมืองเป็นบริบทที่เงียบ

**One useful action:** “ดูทุกพื้นที่” (`?areas=all`) และ “เปรียบเทียบพื้นที่” (เปิดกราฟ) · สลับ “ห้องพัก | ที่พัก” ในคำอธิบายแผนที่: ข้อค้นพบเปลี่ยนเป็น “85% ของที่พักในภูเก็ตที่ระบุอำเภอได้ อยู่ใน 2 อำเภอนี้” (เมืองภูเก็ต · กะทู้ — ภูเก็ตมี 3 อำเภอ จึงไม่โฟกัสทุกอำเภอ) และซ่อนบรรทัดรถไฟฟ้าเพราะไม่มีที่พักใกล้สถานีที่เปิดแล้วในจังหวัดนั้น

## Evidence cue and calculation

แหล่ง: `data/hotels.json` (30,729 แถว; 1,033,157 ห้องจาก 30,650 แห่งที่ทราบจำนวนห้อง) และ `data/area-index.json` (928 เขต/อำเภอ) การคำนวณ: `summarizeAreaInsight` (`js/area-insight.js`) บนแถวที่ผ่าน `filterRows`

| เขต | รหัส | ห้อง | แห่ง |
|---|---|---:|---:|
| คลองเตย | `1033` | 16,886 | 145 |
| ราชเทวี | `1037` | 14,146 | 152 |
| วัฒนา | `1039` | 13,865 | 193 |

จังหวัดที่นำ = จังหวัดที่มีห้องพักที่ระบุเขต/อำเภอได้มากที่สุด (กรุงเทพมหานคร 152,864 ห้อง) สัดส่วน = 53,516 ÷ 152,864 = 35% ตัวหารคือห้องในจังหวัดนั้นที่ระบุเขตได้ ไม่ใช่ทุกห้องและไม่ใช่ตลาดทั้งหมด 9 แห่งในกรุงเทพฯ ที่ไม่ทราบจำนวนห้องไม่อยู่ในทั้งตัวตั้งและตัวหาร (บอกในคำอธิบาย) สัดส่วนใกล้รถไฟฟ้านับเฉพาะห้องของที่พักที่มีพิกัด ทั้งสองฝั่งบอกฐาน

**ไม่ตัดผ่านค่าเท่ากัน และไม่โฟกัสทุกเขต:** ถ้าเขตลำดับถัดไปมีค่าเท่ากับเขตสุดท้ายที่แสดง โฟกัสเหลือเฉพาะเขตที่มากกว่า ถ้าทุกเขตเท่ากันข้อค้นพบเปลี่ยนเป็น “กระจาย” จังหวัดที่มีเขตที่มีค่าไม่เกิน 3 เขตโฟกัสเฉพาะ N − 1 เขตบนสุด
