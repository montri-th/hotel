## First Aha — AHA-01

**ความเข้าใจแรกที่มีประโยชน์:** ห้องพักที่แหล่งบันทึกกระจุกอยู่เขต/อำเภอใด มากแค่ไหนเมื่อเทียบกับทั้งจังหวัด ใกล้สถานีรถไฟฟ้าที่เปิดแล้วแค่ไหนเมื่อเทียบกับเขตอื่น และนอกจังหวัดนั้นมีมากที่สุดที่ไหน ผู้ใช้เริ่มสำรวจระดับพื้นที่ได้ทันทีโดยไม่ต้องเรียนรู้ตัวกรองก่อน

ข้อความเริ่มต้น (snapshot ชีตตรวจ 1 พ.ย. 2569, รุ่น 0.3.2 ข้อมูลเดียวกับ 0.3.1): **“35% ของห้องพักกรุงเทพมหานคร อยู่ใน 3 เขตนี้”** คลองเตย · วัฒนา · ราชเทวี — 53,516 จาก 153,200 ห้อง · แท่ง “ใกล้รถไฟฟ้า ≤ 500 ม.”: 3 เขตนี้ 67% (25,768/38,690) · เขตอื่น 42% (32,732/77,957) ฐานอยู่ในคำอธิบายของแท่ง · ข้อค้นพบรอง “อันดับ 1 นอกกรุงเทพมหานคร: อำเภอบางละมุง ชลบุรี 62,561 ห้อง · มากกว่าทุกเขตของกรุงเทพมหานคร” ตัวเลขทั้งหมดคำนวณจากข้อมูลทุกครั้ง ไม่ใช่ค่าคงที่ใน markup

แผนที่เปิดเป็นเมือง 3 มิติ (preset `city`) ที่โฟกัส 3 เขตนั้นอัตโนมัติ (focus mode `auto`, URL ไม่มี `areas`): สี choropleth `li.supply` สัญลักษณ์ที่พักตามประเภท (ขนาดตามจำนวนห้อง เฉพาะแถวที่มีจุด) สถานีรถไฟฟ้าเป็นวงกลมเงียบ และมวลอาคารมุมโค้งเฉพาะในโฟกัส ส่วนอื่นของเมืองเป็นบริบทที่เงียบ

**One useful action:** “ดูทุกพื้นที่” (`?areas=all`) และ “เปรียบเทียบพื้นที่” (เปิดกราฟ) · สลับ “ห้องพัก | ที่พัก” ในคำอธิบายแผนที่: ข้อค้นพบเปลี่ยนเป็น “85% ของที่พักในภูเก็ตที่ระบุอำเภอได้ อยู่ใน 2 อำเภอนี้” (เมืองภูเก็ต · กะทู้ — ภูเก็ตมี 3 อำเภอ จึงไม่โฟกัสทุกอำเภอ) และซ่อนบรรทัดรถไฟฟ้าเพราะไม่มีที่พักใกล้สถานีที่เปิดแล้วในจังหวัดนั้น

## Evidence cue and calculation

แหล่ง: `data/hotels.json` (30,729 แถว; 1,033,157 ห้องจาก 30,650 แห่งที่ทราบจำนวนห้อง) และ `data/area-index.json` (928 เขต/อำเภอ) การคำนวณ: `summarizeAreaInsight` (`js/area-insight.js`) บนแถวที่ผ่าน `filterRows`

| เขต | รหัส | ห้อง | แห่ง |
|---|---|---:|---:|
| คลองเตย | `1033` | 16,886 | 145 |
| ราชเทวี | `1037` | 14,146 | 152 |
| วัฒนา | `1039` | 13,865 | 193 |

จังหวัดที่นำ = จังหวัดที่มีห้องพักที่ระบุเขต/อำเภอได้มากที่สุด (กรุงเทพมหานคร 152,864 ห้อง) สัดส่วน = 53,516 ÷ 153,200 = 35% ตัวหาร (ตั้งแต่ 0.3.1) คือห้องทั้งจังหวัดในตัวกรอง รวม 336 ห้องที่แหล่งระบุได้แค่จังหวัด ประโยคจึงอ่านได้ตรงโดยไม่ต้องมีคำขยาย 9 แห่งในกรุงเทพฯ ที่ไม่ทราบจำนวนห้องไม่อยู่ในทั้งตัวตั้งและตัวหาร (อยู่ใน “วิธีนับ”) สัดส่วนใกล้รถไฟฟ้านับเฉพาะห้องของที่พักที่มีพิกัด ฐานทั้งสองฝั่งอยู่ในคำอธิบายของแท่ง

**ไม่ตัดผ่านค่าเท่ากัน และไม่โฟกัสทุกเขต:** ถ้าเขตลำดับถัดไปมีค่าเท่ากับเขตสุดท้ายที่แสดง โฟกัสเหลือเฉพาะเขตที่มากกว่า ถ้าทุกเขตเท่ากันข้อค้นพบเปลี่ยนเป็น “กระจาย” จังหวัดที่มีเขตที่มีค่าไม่เกิน 3 เขตโฟกัสเฉพาะ N − 1 เขตบนสุด

## States

| State | ผลบนหน้าจอ |
|---|---|
| โหลด | การ์ดเปิดเว็บ (`js/launch.js`) จนข้อมูลพร้อม |
| ไม่พบตามตัวกรอง | “ไม่พบที่พักตามตัวกรองนี้” + ล้างตัวกรอง |
| เขตที่ไม่มีที่พัก | measured zero ของชุดข้อมูลนี้ + “ดูพื้นที่ที่พบ” |
| ไม่ทราบจำนวนห้อง | นับเป็นแห่ง ไม่นับเป็น 0 ห้อง; เขตที่ไม่ทราบทั้งหมดเป็นลายทแยง (no data) |
| แผนที่โหลดไม่ได้ | ข้อค้นพบ แผง กราฟ และตารางยังใช้ได้ พร้อมปุ่มลองใหม่ |
| ขอบเขตจังหวัดโหลดไม่ได้ | รายงานและลองใหม่เมื่อขอครั้งถัดไป แผงไม่พึ่งขอบเขต |
| เลือกที่พักที่มีพิกัด (0.3.2) | แผนที่เปลี่ยนเป็น 3 มิติ กล้อง 2-point ที่อาคารที่หมุดอยู่ในขอบ (“อาคารของที่พัก”) |
| หมุดไม่อยู่ในขอบอาคาร (0.3.2) | กล้อง 2-point ที่อาคารใกล้หมุดที่สุดภายใน 300 ม. (ไม่มีก็โหลดถึง 800 ม.) หมุดอยู่ในภาพ ป้าย “อาคารใกล้หมุด” — ไม่นับใน “ที่พักในอาคารนี้” |
| ไม่มีอาคารบนแผนที่ในระยะ 800 ม. | กล้อง 2-point ที่พื้นที่รอบหมุด (กล่อง 90 ม.) |
